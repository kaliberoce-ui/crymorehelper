Privacy Policy — CrymoreHelper

Last updated: 2026-09-06

Summary: CrymoreHelper currently does not collect, store remotely, transmit, sell, or share any data. Everything it handles today stays on your own computer, inside your browser's local extension storage. This policy may be updated at any time — see "Changes to this policy" below — so check back here for the current version.

What the extension does

CrymoreHelper is a browser extension that runs only on https://login.geotester.com/*. It reads and fills form fields on the GeoTester compaction worksheet page to speed up routine data entry. It never submits or saves a GeoTester worksheet automatically — every save is performed manually by the person using it, after they review what was filled in.

What data it stores, and where

  • Saved setup profiles, personnel/equipment preferences, panel settings, and tin-tracking history are stored using chrome.storage.local — a storage area private to this extension and this browser profile.
  • An optional, off-by-default "Tin Manager Cross-Tab Safe Mode" feature coordinates tin reservations between your own open browser tabs via the extension's own background service worker. This never leaves your browser and involves no external server.
  • As of this version, none of this data is sent to any server. The extension has no backend, no analytics integration, and makes no network requests of any kind.
  • This data is only ever read by the extension itself, only within GeoTester worksheet pages.

What data it does NOT currently do

  • It does not collect browsing history, personal information, or worksheet content for any purpose beyond filling the fields you asked it to fill.
  • It does not transmit anything to the developer or any third party.
  • It does not use cookies, trackers, or analytics.
  • It does not run on any website other than login.geotester.com.

Future data collection

CrymoreHelper is under active development. Future versions may collect, use, or process additional data — including but not limited to diagnostic, usage, or technical information — for purposes such as improving security, reliability, or functionality. Any such change would only take effect in a future release, would be reflected in an updated version of this policy before or alongside that release, and would only use permissions the extension actually requests through the Chrome Web Store at that time.

Permissions

  • storage — to save your profiles and settings locally, as described above.
  • Host access to login.geotester.com — to read and fill worksheet fields on that site only.
