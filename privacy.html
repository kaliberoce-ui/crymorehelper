Privacy Policy — CrymoreHelper

Last updated: 2026-09-06

Summary: CrymoreHelper currently does not collect, store remotely, transmit, sell, or share any data. Everything it handles today stays on your own computer, inside your browser's local extension storage. This policy may be updated at any time — see "Changes to this policy" below — so check back here for the current version.

What the extension does

CrymoreHelper is a browser extension that runs only on https://login.geotester.com/*. It is a professional/workplace lab tool for GeoTester compaction worksheets — it reads and fills form fields to speed up routine data entry. It never submits or saves a GeoTester worksheet automatically — every save is performed manually by the person using it, after they review what was filled in.

What data it stores, and where

  • Saved setup profiles, personnel/equipment preferences, panel settings, and tin-tracking history are stored using chrome.storage.local — a storage area private to this extension, this browser profile, and this device. It is not a cloud account and is not synced anywhere by the extension itself.
  • An optional, off-by-default "Tin Manager Cross-Tab Safe Mode" feature coordinates tin reservations between your own open browser tabs via the extension's own background service worker. This never leaves your browser and involves no external server.
  • As of this version, none of this data is sent to any server. The extension has no backend, no analytics integration, and makes no network requests of any kind — confirmed by inspection of the extension's source: it contains no fetch, XMLHttpRequest, remote-script loading, or eval-style dynamic code execution anywhere.
  • This data is only ever read by the extension itself, only within GeoTester worksheet pages.

What data it does NOT currently do

  • It does not collect browsing history, personal information, or worksheet content for any purpose beyond filling the fields you asked it to fill.
  • It does not transmit anything to the developer or any third party.
  • It does not use cookies, trackers, or analytics.
  • It does not run on any website other than login.geotester.com.
  • It does not download, fetch, or execute any remote code. Everything the extension runs is contained in the version you installed from the Chrome Web Store.

Security

  • All data handled by the extension stays inside Chrome's own per-extension storage sandbox, which other extensions and ordinary web pages cannot read.
  • The extension requests the minimum permissions needed for its function (see "Permissions" below) and nothing broader, such as access to all websites or your browsing history.
  • Profile import/export is a manual, user-initiated action. If you export a profile to a file and share that file yourself, anything in it is then outside the extension's control — treat an exported profile file the same as any other document you choose to send someone.
  • Because everything is local, the practical way to remove all data the extension holds is to use its own "Full troubleshooting reset" option in Settings, or to remove the extension from Chrome entirely (chrome://extensions) — either immediately and permanently deletes its local storage.

Future data collection

CrymoreHelper is under active development. Future versions may collect, use, or process additional data — including but not limited to diagnostic, usage, or technical information — for purposes such as improving security, reliability, or functionality. Any such change would only take effect in a future release, would be reflected in an updated version of this policy before or alongside that release, and would only use permissions the extension actually requests through the Chrome Web Store at that time. Regardless of what is added in the future, this policy commits that any future data collection will:

  • never be used to sell your data, or share it with third parties for their own marketing or advertising purposes;
  • never be broader than necessary for the stated security, reliability, or functionality purpose;
  • be disclosed in this policy, and where required, surfaced in the extension itself, before it takes effect; and
  • comply with Google's Chrome Web Store Developer Program Policies, including the Limited Use requirements for user data.
